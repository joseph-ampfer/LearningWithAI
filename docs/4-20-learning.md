I learned about post-processing effects, in comparison of Unreal and Unity.
I saw a game with impressive visuals in a game jam, and used AI to learn how it was done.
Post-processing is modifying the image after everything in the scene was processed, but before it is displayed on the screen. So it gives a chance to modify how the user sees things.
I learned that chromatic abberation is easy to do in Unity and Unreal. It seperates the red, green, blue channels to give a trippy effect.

AI helped me relearned what a box blur was, and that I implemented that at a low level when I first started programming. It involves taking a pixel, looking at all the surrounding 
pixels, and averaging those values to assign the current pixel to that value.
The edge cases are the corner and edge pixels.
